本机转换，怎么开始？

普通 PSD、AI、PDF 和 .figimport 离线包可以直接在插件中选择。只有 EPS / PS 或需要增强转换时，才需要打开本机程序。

已经准备好这台电脑

  1. 将插件 ZIP 完整解压，双击其中的 启动本机转换.cmd。
  2. 在窗口中点击 复制连接码。请保持这个窗口打开。
  3. 回到 Figma 插件，开启 本机增强，粘贴连接码，点击 连接本机程序，然后选择文件。

首次使用这台电脑

当前为 Windows 预览版，尚未提供包含全部运行环境的安装器。首次需要准备以下组件，之后直接双击启动即可。

  1. 安装 Python 3.12（Windows 官方下载），保留安装器中的 Python Launcher 和 Tcl/Tk 选项。启动文件打不开窗口而进入本页时，请先检查这一步。
  2. 安装 Node.js（官方下载安装器，建议 24），保留 npm。安装完成后重新双击启动文件。
  3. 本机窗口提示缺少转换组件时，点击 安装所需组件并启动。程序将联网从 PyPI / npm 下载组件到解压目录，不需要手动输入命令。首次下载可能需要几分钟，请将文件夹放在有写入权限的位置。
  4. 导入 EPS / PS 还需安装 Ghostscript（Windows 64 位官方下载）。安装后重新连接即可。其 AGPL / 商业许可说明见 第三方许可。

连接码是什么？

它是本机程序每次启动生成的临时密码，让插件确认连接权限。无需注册、无需自己设置。点击“复制连接码”后粘贴即可，重启程序后需要重新复制。连接码不会保存到 Figma 文件。

遇到问题

  • 未连接：确认本机程序窗口仍然打开，再点连接。插件无法直接启动电脑上的程序。
  • 连接码失效：回到当前本机窗口重新复制，粘贴后再连接。
  • 已有程序使用端口：使用之前打开的本机窗口，或关闭旧窗口后重新启动。
  • 组件安装失败：检查网络和文件夹写入权限后重试；安装日志在同目录的 helper-setup.log。
  • 已有 .figimport 包：在插件中直接选择该文件即可，无需连接码。
  • Mac：当前本机程序只支持 Windows，插件的普通导入仍可使用。

源文件在本机转换。导入后的图层会进入当前 Figma 文件，请按文件的共享范围使用。本程序关闭后停止服务，并清理本次临时转换文件。
