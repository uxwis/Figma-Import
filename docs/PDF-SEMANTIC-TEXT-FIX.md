# 真实 PDF 文字重影修复 · preview.15

用户提供的本地 PDF 为 990,527 字节、单页 A4、带标签的 PDF 1.7。文件未修改，也未上传转换服务。

## 原因与修复

页面先在 `/Artifact` 中绘制文字轮廓和其他图形，再用带 MCID 的文字对象携带可搜索、可复制的 Unicode。字体名为 `FigmaGlyphs`，类型为 Type3；CharProc 只有 d1 宽度/边界声明，不绘制字形。preview.14 将这套原本不出墨的语义文字作为可见 TEXT，又保留 Artifact 中的真实文字轮廓，所以两套字形叠加。先前针对真实字体路径的去重无法覆盖此结构。

新处理只针对这类空 Type3 语义字体：将每个字形的边界与 Artifact 路径对应，按完整字形/文本片段验证尺寸、基线、同一绘制容器与填充，替换原文字路径；原生 TEXT 插回原路径位置，保留颜色、透明度与父级裁剪。使用空间索引避免逐字扫描全部路径。字体的三位小数宽度会累积微小误差，匹配容差为 0.15 个源单位；单独验证预留的上伸部空间。倒置的抬高星号/连字符边界在恢复时修正。

只采用能独立匹配字形的原路径，排除落在文字范围内的其他装饰路径。不能完整对应、不同绘制容器或填充不一致时，保留源外观并隐藏这套空字形语义文字，完成页明确提示。未带可对应标记的空字形内容也保持隐藏，避免制造重复外观。普通有墨 Type3 字体不走这条替换流程。

段落合并同时处理源 Unicode 已含换行的情况，不再多插一行；每段保存累计字形数量及原轮廓源 ID。缺少实际字体时继续使用默认字体并明确提示。
