# 可编辑渐变文字修复

社区版 `2.1.0-preview.10`，2026-10-14。

上一版已修复 SVG 智能对象的原生叠加，文字仍被通用叠加逻辑包装为“文字 + 缓存图片蒙版 + 渐变矩形”。文字内容虽然存在于 TEXT 节点中，可见渐变仍依赖缓存图片。

本次将正常混合的文字叠加直接写入 TEXT 的原生 fills，保留文字内容、字体/字号区间和编辑能力。Figma 支持通过文字 fills 和 setRangeFills 修改文字画笔。[官方文字 API 说明](https://developers.figma.com/docs/plugins/working-with-text/)

全覆盖渐变统一覆盖各样式区间的原颜色，不覆盖其字体、字号、字距和行距；透明渐变保留底层区间颜色及渐变透明度。渐变在文字完成原生布局及字形定位后，按 PSD 效果的参考坐标映射到整个文字节点。画板和父组变换会同步参考坐标。原填充为零时先以可见字形测量墨迹位置，再应用最终效果，避免透明填充造成定位失败。

无可加载字体或不支持的文字变换时，仍明确报告缓存回退，同时保留渐变外观；特殊混合效果不会被误报为原生渐变文字。

对用户提供的 PSD 完整解析后，有 6 处渐变文字：3 处文档文字和 3 处嵌入智能对象文字。本地源码和最终打包浏览器回归检查它们均为 TEXT，具有 GRADIENT_LINEAR 填充，无 IMAGE 填充，无子蒙版/叠加矩形。总文字为 148，图片由 26 降为 20，蒙版由 16 降为 10。原有 75 个纯矢量智能对象仍通过检查。

回归还覆盖混合字体和字号、透明渐变、父组旋转/缩放、画板偏移、多行与文本框、零填充时的墨迹定位，以及无字体/变换回退。测试使用本地节点环境，真实 Figma 的字形与最终显示仍需核对。源 PSD 未改写，社区线上插件未重新发布。

关闭旧插件窗口，从 `D:\WB\导入figma插件\community\manifest.json` 重新运行 FigImport，再次导入原 PSD 即可使用修复。
