# 段落、裁剪与文字重影 · preview.14

AI、EPS 和 PDF 共用 PDF 解析管线。TJ 数值字距不再切成独立图层，改为 TEXT 的范围字距。相邻片段与连续行合并为一个文本层，保留字号/字体/颜色区间、原行距、对齐及首行缩进。使用替代字体时先测量最长显式行，避免新增自动换行。段落间距、多栏、方向、独立短文本及不同段落标签是合并边界。

重复整页裁剪直接省略。其他矩形裁剪需要证明包含所有绘制内容才删除；真正截掉内容时使用透明 Frame 的 Clip content。曲线、复杂复合路径与文字蒙版继续保留。源字形实际几何用于文字裁剪范围证明，不使用估计的文字框。

重复字形去除需要完整轮廓匹配（含孔洞）、相同位置、正常不透明颜色及一致裁剪/合成范围。坐标容差按字形缩放限制在 0.015–0.1 源单位，容纳 PDF 字体与路径的舍入；不按文字包围盒删除路径。缺少源字体轮廓或无法证明一致的路径会保留。EPS/PS 转换时显式清空 NeverEmbed，保留标准字体子集用于匹配。
