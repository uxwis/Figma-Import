# 小红书图文宣传素材

## 发布内容

- 推荐标题：做了个插件，把设计稿搬进Figma
- 正文：复制 `body.txt`，文末已包含话题标签。
- 配图：按 `01` 到 `05` 顺序上传 `images/` 内的 5 张 PNG。
- 尺寸：全部为 **1200 × 1600 px，3:4**。
- 预览与复制：打开 `index.html`。

备选标题：

1. PSD和AI，试试这样导入Figma
2. 旧设计稿，换到Figma接着改
3. 给设计师做了个文件搬家工具

## 配图顺序

1. `01-cover.png`：PSD / AI 导入 Figma，介绍插件用途。
2. `02-content.png`：可保留的图层与内容，明确编辑能力取决于源文件。
3. `03-workflow.png`：当前插件真实界面与三步操作。
4. `04-formats.png`：各格式的支持条件。
5. `05-notes.png`：字体、效果、大小限制与社区搜索入口。

## 内容依据

基于当前 `community/` 版本 `2.1.0-preview.7` 的 README、界面、清单和文件限制整理。文案使用开发者第一人称，适合插件作者本人发布；没有写未经核实的上线状态、价格、还原率、导入耗时或用户数量。

作者已确认插件正式上线 Figma 社区，文案与配图已按上线状态调整。按作者要求，发布正文与图片不放外链，统一引导在 Figma 社区搜索「PDF/AI/EPS/PSD」。本素材包未执行小红书发布。

第 03 张的插件内容来自当前构建代码的浏览器渲染截图，外侧标题栏用于排版。第 01、02 张的矢量插画为原创功能示意，图内有标注，不是实测导入结果。

## 修改与重建

`source/build.mjs` 包含五张竖版图的 HTML/CSS/SVG 排版代码，`source/pages/` 保存对应 HTML。已沿用社区素材的紫色、米白和淡绿色，针对竖屏重新排版。

在项目根目录运行：

```powershell
node community/xiaohongshu-kit/source/build.mjs
```

脚本会重新抓取当前插件界面、导出 PNG、生成预览页和尺寸检查记录。只修改本素材目录，不改动插件代码或上一套社区发布素材。
