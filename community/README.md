# PDF / AI / EPS / PSD 导入器 · 社区版预览

本仓库只维护此社区版，community/ 是唯一产品源码、依赖与构建入口。转换引擎内嵌，无需安装本机转换服务。

## 使用

开发者在 Figma 桌面端导入本目录的 `manifest.json`，运行名称带“社区版”的插件。正式发布后，社区用户只需打开插件面板并选择文件，无需下载项目文件夹或安装转换程序。

当前清单沿用 FigImport 社区条目的插件 ID，供原社区条目更新使用。当前修复构建为 `2.1.0-preview.15`，窗口标题为“FigImport”；切换开发插件时核对清单路径及 `build-info.json`，避免混用旧窗口。唯一开发插件注册入口为本目录 manifest.json。

`preview.15` 针对真实 PDF 复现并修复另一类文字重影：Figma 导出的部分 PDF 用 Artifact 中的路径显示文字，另用空 Type3 字形和 Unicode 记录搜索/复制内容。现在依据这套字体的逐字边界与源路径对应，用原生 TEXT 替换完整匹配的轮廓，并保持原来绘制顺序、颜色、透明度和裁剪位置；不再把空字形文字直接叠画在原轮廓上。不同容器或无法完整匹配的内容保留原外观，将可编辑语义文字隐藏并明确提示。还修复自带换行重复换行，以及抬高的星号、连字符边界倒置问题。用户 PDF 本地回归得到 44 个可见 TEXT，对应的 44 个轮廓图层全部移除，6 个原始图片保留；44 段文字逐段对照 Unicode 内容通过。字体仍使用默认字体并提示，复杂透明蒙版的既有限制未变化。

`preview.14` 修复 AI/EPS/PDF 文字碎片、重复字形重影与过多裁剪。TJ 字距调整保留在样式区间内；同一文本对象内的连续行和相邻片段合为一个 TEXT，保留原行距、对齐、首行缩进和混合字号/颜色。跨文本对象仅在段落标签或连续排版可确认时合并，独立文本块、多栏及大段间距保持边界。覆盖整页、重复以及没有截掉内容的矩形裁剪会被移除；真正需要的矩形裁切成为透明 Frame 的 Clip content，复杂形状和文字裁剪仍保留蒙版。文字重影按源字体完整轮廓、位置、颜色与裁剪上下文匹配去重，包含孔洞验证及受限坐标舍入容差；装饰图形不会仅因覆盖文字区域而被删除。EPS/PS 转 PDF 时嵌入标准字体子集，以便读取源字形。

在 `4190626.ai` 中，原先 7 个文字片段现在是标题和三行正文两个 TEXT；裁剪蒙版从 21 个降为 4 个，另有 4 个实际裁切 Frame。PDF 未必携带原始编辑软件的段落语义：无标签文件按文本对象与版面恢复，已转曲且没有文字编码的内容仍不能自动恢复段落。字体替代继续明确提示核对。

`preview.13` 加速具有大量重复纹样的 AI/PDF：仅对连续、同色、不透明、无描边且边界互不重叠的路径分批合并，每批最多 128 个源对象和约 64 KiB 路径数据，不跨越文字、图像、组或裁剪。每个子路径仍可进入矢量编辑，源对象 ID 保留在节点数据中；不将图形转为图片。重复纹样共享一个矢量节点，独立节点数量会减少。

PDF/AI/EPS 有有效文字编码的内容均生成原生 TEXT，支持原生填充、描边、渐变和可编辑文字蒙版；不可见文字保留为隐藏 TEXT。竖排按字形位置保留可编辑文本，特殊字体/排版会提醒核对。缺少字体用默认字体；没有可加载字体时明确失败，禁止悄悄将文字转曲。编码缺失时用替代字符保留位置并明确提示，已经转曲的原始路径无法自动恢复文字。

`preview.12` 修复 AI/EPS 创建图层阶段卡住、取消无响应：默认字体列表改为线性去重，每次导入只构建一次；原字体已可用时不枚举替代字体，同字体的文本段复用选择结果。字体列表读取限时 15 秒，单个字体加载限时 5 秒，同一字体选择的总等待限时 20 秒。挂起的原字体可跳过并继续默认字体，仍保留替代提示；读取和加载等待均可取消，迟到结果不会继续创建节点。节点创建按时间片让出执行并更新当前阶段，取消时清理本次节点。

`preview.11` 修复 AI/EPS/PDF 文字导入：有有效 Unicode 的普通文字按文本段生成 Figma TEXT，保留内容、字体、字号、颜色、字距、基线与各段起点。原字体缺失或加载失败时优先用默认字体 Inter Regular，无法加载时依次尝试其他可用默认字体；完成页“需要注意”明确提示原字体缺失、已用默认字体替代且文字仍可编辑。已在源文件转曲的路径不能恢复为文字；编码缺失及特殊排版在 preview.13 起保留可编辑内容并明确提示。非等比缩放和倾斜优先保留文字编辑能力并提示核对排版。

`preview.10` 修复渐变文字的缓存图片蒙版叠加。正常混合的文字颜色/渐变叠加直接成为 TEXT 节点的原生填充，保留内容、字体/字号区间、字距、行距及编辑能力；全覆盖渐变统一覆盖原区间颜色，透明渐变保留底层区间颜色和效果透明度。文字填充为零时仍正确测量字形定位，随后应用可见的渐变效果。无字体可加载、不支持的排版或特殊叠加继续明确报告回退，并保留渐变外观。

`preview.9` 修复矢量智能对象的颜色/渐变叠加依赖缓存图片蒙版的问题。对支持的 SVG 对象，将完全不透明、正常混合的叠加直接写入原始路径的填充和描边，保留空心轮廓、路径透明度以及统一的渐变坐标；不会新增矩形或位图蒙版。半透明叠加、特殊混合、内嵌图片/滤镜及复杂源渐变继续明确报告回退。实际节点统计会检查 IMAGE 填充，避免将带图片的矢量容器计为纯矢量。

同时修复部分 Illustrator SVG 的图形画在 viewBox 外的问题：仅在计算出的绘图区与 PSD 保存尺寸吻合时调整画布边界，恢复图标位置；正常 SVG 的原有留白保持不变。新增 svgpath 2.6.0 固定依赖及 MIT 许可，随插件内嵌，无需网络加载。

`preview.8` 修复普通 PSD 文字因字体名称或字重匹配失败而整层转为图片：支持字体族内嵌字重、常见 PostScript 名和缩写；优先加载原字体，缺字体或字体加载失败时使用可用字体创建原生可编辑文字，保留内容、字号、颜色、字距、行距及各样式区间。替代字体会在完成页提示，原字体与实际替代字体保存在节点数据中；字体替代不代表字形或排版完全一致。无可用字体、竖排/弯曲及不支持的文字变换仍保留原始外观。PDF/AI/EPS 文字在 preview.11 起使用默认字体保留编辑能力。

`preview.7` 修复发布时的 `plugin code exceeds max size of 15MB`：完整 UI 脚本使用 gzip 与适合 HTML 的 Base85 编码内嵌，打开插件时在本地恢复原始代码。发布所需的 `manifest.json`、`code.js`、`ui.html` 合计约 14.80 MB（十进制）。构建和打包均强制检查合计体积小于 15,000,000 字节；ZIP 压缩后的大小不作为发布体积依据。没有裁剪引擎、字体资源或导入格式，也没有添加网络依赖。源码包保留可读源码。

`preview.6` 将窗口固定为 440 × 520px，按展开“导入说明”所需的高度设置；展开、收起及切换页面均不自动改变窗口大小。常规界面无需滚动，特别长的异常信息仍可滚动查看。

`preview.4` 精简首页“导入说明”，删除底部版本栏、诊断下载和验收包导出；完成页仅显示结果统计及最多三类重要提醒。内部版本检查、诊断与节点元数据仍保留。

`preview.3` 修复 PSD 内嵌 PDF 智能对象及 PDF/AI 导入中，空字形被转换成单独 `Z` 路径而使导入中断的问题。空字形不创建矢量节点，仍保留字形宽度、字距及词距；有轮廓的字形继续正常导入。

| 文件 | 处理方式 |
|---|---|
| PSD / PSB | 插件内解析图层、形状、文字、智能对象及已支持效果 |
| PDF | 直接选择或拖入；每页生成一个画板，保留可解析路径、可编辑文字与图片；扫描页仍为图片 |
| 包含 PDF 兼容内容的 AI | 插件内 PDF 解析 |
| EPS / PS、可读取 PostScript 内容的旧 AI | 内置 Ghostscript WebAssembly → PDF → Figma 节点 |
| .figimport | 直接导入已有转换包，无需连接服务 |

EPS/PS 引擎及资源内嵌在 `ui.html` 中，首次转换时才启动后台线程；转换不请求 CDN、本机服务或云端。清单的网络权限为 `none`。导入后的节点会按 Figma 自身的保存机制进入当前文件。

EPS/PS（包括 PostScript AI）上限 64 MB、转换时限 3 分钟、转换 PDF 上限 128 MB；其他源文件上限 256 MB。可以取消，结束后释放转换线程。错误会显示原因，不会自动把整页转换成图片作为成功结果。

选择或拖入后先读取文件头检查体积，超限时不读取完整文件。PSD/PSB 在解码前检查图层、蒙版和嵌入 PSD 的结构，以 2 GiB 像素解码预算提前拦截；同时保留原有文档像素尺寸保护。预检不解码图层像素、不降低清晰度，也不能保证预测所有运行时内存不足；相关错误统一显示中文拆分建议。

## 还原范围

EPS/PS 的输出以路径、可解析的可编辑文字、图片和画板等组成，不恢复原 Illustrator 的全部专有图层语义。未嵌入的字体可能由 Ghostscript 替换；发生替换时保留诊断。PSD/PDF 的复杂效果限制与之前的解析器一致，内置引擎不会自动修复尚未支持的阴影等高线、智能对象变形或复杂合成。

## 构建与测试

需要 Node.js 22.13+，仅开发者需要；社区用户不需要 Node.js。

```powershell
cd community
npm ci
npm run build
npm test
$env:PSD_TEXT_SAMPLE = "C:/你的样本目录/森篮.psd"
npm run test:text
npm run test:text-gradient
$env:PSD_VECTOR_SAMPLE = "C:/你的样本目录/森篮.psd"
npm run test:vector
npm run test:bundle
npm run test:browser
npm run test:ui
$env:SAMPLE_DIR = "C:/你的样本目录"
npm run test:compiled
npm run package
```

本目录拥有唯一产品源码与锁文件；后续解析器修复和发布均在此目录完成。内置引擎是固定版本的原始供应商文件，来源与校验值见 `licenses/GHOSTSCRIPT-WASM.json`。

打包生成 `dist/*-plugin.zip`（开发插件测试包）和 `dist/*-source.zip`（社区版项目源码与引擎二进制）。明确文件清单排除真实样本、测试输出、虚拟环境、字体、CMD 和 Python 本机程序。

`preview.9` 对同一用户 PSD 检查完整解析树和创建树：75 个矢量智能对象实例的子树中均无图片填充和蒙版，69 个效果（60 个纯色、9 个线性渐变）直接应用在原始路径上；图片节点由 95 降为 26，蒙版由 85 降为 16，可编辑文字仍为 148。新增回归检查真实 PSD 编解码、多个子路径的统一渐变、旋转/缩放/倾斜/画板偏移、描边与透明度、图片统计及复杂效果回退。测试环境与真实 Figma 渲染器的区别仍适用。
